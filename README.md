# Math Tool Box｜數學工具箱

一個以原生 HTML、CSS 與 JavaScript 製作的輕量化數學工具網站，將常用的數學練習與數字查詢功能集中在同一個首頁。無需安裝套件或建置工具，使用瀏覽器即可開啟。

## 功能特色

- **工具集中管理**：透過首頁快速瀏覽及開啟數學工具。
- **即時搜尋**：依工具名稱、說明、分類及關鍵字搜尋。
- **分類篩選**：可依「練習與測驗」及「數字工具」分類瀏覽。
- **深色／淺色主題**：首頁與工具頁共用主題設定；主題偏好會嘗試儲存在瀏覽器 `localStorage`。
- **響應式版面**：支援桌面及較小螢幕的瀏覽。
- **容易擴充**：新增工具 HTML 檔案並更新首頁的 `tools` 清單，即可整合新工具。

## 目前提供的工具

### 1. 平方數隨機抽考

用於練習 1～30 的平方數與平方根。

- 可選擇考試範圍：1～10、1～20 或 1～30。
- 可選擇題型：平方、平方根或兩種混合。
- 可選擇每回合題數：10 題、20 題、30 題或範圍內全部題目。
- 題目會隨機排序。
- 自動判斷答案並顯示正確答案。
- 顯示作答進度、答對題數及正確率。
- 可選擇在回合結束後重新練習答錯或跳過的題目。
- 支援按 Enter 確認答案或前往下一題。

### 2. 正整數因數查詢

輸入正整數，列出該數的所有正因數。

- 顯示完整的正因數清單及因數總數。
- 提供數字鍵盤、退格與清除功能。
- 支援實體鍵盤輸入。
- 可使用 `Enter` 查詢、`Backspace` 刪除最後一位、`Esc` 清除輸入。
- 使用配對因數的方式搜尋，迴圈只需檢查至平方根範圍。
- 檢查輸入是否為有效正整數，並避免超出 JavaScript 安全整數範圍。

## 專案結構

建議將首頁及各工具 HTML 檔案放在同一個資料夾，例如：

```text
math-tool-box/
├── index.html
├── 平方數隨機抽考.html
├── 因數查詢.html
└── README.md
```

> 注意：上方檔名是建議的專案檔名。首頁 `index.html` 中的 `tools` 清單必須與實際 HTML 檔名完全一致，否則連結可能無法正常開啟。

## 如何使用

### 方法一：直接在瀏覽器開啟

1. 下載或複製專案檔案。
2. 確認 `index.html` 與各工具 HTML 檔案位於同一個資料夾。
3. 使用瀏覽器開啟 `index.html`。
4. 透過搜尋框、分類按鈕或工具卡片選擇需要的功能。

### 方法二：使用本機 HTTP 伺服器

若希望以本機網站的方式測試，可在專案資料夾中執行：

```bash
python -m http.server 8000
```

接著在瀏覽器開啟：

```text
http://localhost:8000
```

此方法需要電腦已安裝 Python。一般使用情況下，直接開啟 HTML 檔案即可。

## 如何新增數學工具

1. 將新工具製作成獨立的 HTML 檔案。
2. 把檔案放到 `index.html` 所在的資料夾。
3. 開啟 `index.html`，找到 JavaScript 中的 `const tools = [...]`。
4. 在陣列中新增一筆工具設定。

例如：

```javascript
{
  title: "新工具名稱",
  description: "簡短說明這個工具的用途。",
  icon: "＋",
  category: "number",
  categoryName: "數字工具",
  href: "新工具.html",
  keywords: "關鍵字1 關鍵字2 關鍵字3",
  accent: "#8de6ff",
  glow: "rgba(83,216,255,.16)"
}
```

欄位說明：

| 欄位 | 用途 |
| --- | --- |
| `title` | 首頁顯示的工具名稱 |
| `description` | 工具簡介 |
| `icon` | 工具卡片上的圖示文字 |
| `category` | 分類識別值 |
| `categoryName` | 顯示給使用者的分類名稱 |
| `href` | 工具 HTML 檔案路徑或檔名 |
| `keywords` | 提供首頁搜尋使用的關鍵字，以空格分隔 |
| `accent` | 卡片強調色 |
| `glow` | 卡片裝飾光暈顏色 |

新增完成後，請確認檔名、分類與關鍵字正確，並實際點選首頁卡片測試連結。

## 技術

- **HTML5**：網頁結構與工具介面。
- **CSS3**：版面配置、響應式設計、卡片效果及深淺色主題。
- **原生 JavaScript**：工具搜尋、分類篩選、隨機出題、答案判斷、因數計算及主題切換。
- **Browser APIs**：使用 `localStorage` 儲存主題偏好，並透過鍵盤事件提供操作功能。

本專案目前不需要前端框架、第三方 JavaScript 套件、資料庫或建置流程。

## 主題設定

首頁與工具頁使用相同的 `localStorage` key：`math-toolkit-theme`，用來同步深色或淺色主題。工具頁也會讀取網址中的 `theme` 參數，以接收首頁傳入的主題。

若瀏覽器不允許存取 `localStorage`，程式會嘗試繼續套用頁面主題，但跨頁面的偏好保存可能無法正常運作。

## 相容性

建議使用近期版本的 Chrome、Edge、Firefox 或 Safari。因本專案使用原生瀏覽器功能，實際顯示仍可能因瀏覽器版本與裝置而略有不同。

## 注意事項

- 這是一個前端靜態網站，目前沒有帳號系統、雲端資料同步或後端服務。
- 作答統計屬於頁面當次使用期間的即時結果；目前沒有將測驗紀錄永久保存的功能。
- 新增工具時，請確認首頁設定中的 `href` 與實際檔名完全一致。
- 請勿將本 README 中的範例檔名誤認為目前上傳檔案的實際名稱；整理專案時可依此命名，或同步修改 `tools` 清單。
